# Voter App — Privacy Policy

The public privacy policy for the **Voter App** Android application
(`com.voterapp.mobile`), published via GitHub Pages.

Google Play requires a privacy policy at a publicly reachable URL, and will
flag or remove an app whose policy link stops working. This lives on GitHub
Pages rather than on the app's own server so it does not depend on the
`voterapp.duckdns.org` domain or on that server staying up.

## Publishing

GitHub Pages is enabled from the `main` branch, root folder. Editing
`index.html` and pushing republishes it within a minute or two.

## Where this URL is used

- Google Play Console → Store presence → Privacy policy
- Google Play Console → App content → Data safety
- `STORE_LISTING.md` in the `voterapp_mobile` project

A copy is also served from the app's own server at `/privacy-policy/`. If the
two ever differ, **this one is authoritative** — it is the one linked from the
Play listing.
